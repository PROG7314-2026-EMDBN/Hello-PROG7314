# 🎯 PROG7314 – Programming 3D / Open Source Coding
## 📖 Overview
Welcome to PROG7314 – Programming 3D! 🚀 This repository contains structured content for the module, including:
* 🚀 Lecture resources which will be updated as we go
* 📝 Activities and Coding exercises
* 📚 Information about the module

This module focuses on advanced native Android app development using Kotlin, with a strong emphasis on hands-on, open-source coding.

## 📂 Repository Structure
Each folder corresponds to a module topic. Inside, you'll find activities and resources that I will add as we go.

## 😎 What’s the reason for this module in BCAD?
By now, you’ve already been exposed to Kotlin with Jetpack Compose. PROG7314 is where we continue to explore open-source coding and mobile development:
* 📱 Build native Android apps using Kotlin
* 🧩 Apply OOP concepts in a mobile environment and harness on-device sensors.
* 🗄 Work with local databases (RoomDB) and JSON
* ☁️ Integrate Firebase and Supbase for authentication, databases, and file storage
* 🌍 Build Android Apps that integrate with other services including APIs.

## 🏆 How will the module be taught?
* 🎓 The focus is on preparing you for real software development, not just passing assessments.
* 💡 You will write code, break things, debug, and fix them — this is how real learning happens.
* 📱 Every learning activity results in a working Android application.
* 🧠 Industry context and best practices will be continuously emphasised.
If you engage consistently, you’ll leave this module with apps you can confidently demonstrate.
